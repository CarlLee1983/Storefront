# 示範資料

`catalog.json` 描述示範用的分類、商品與圖片，`images/` 是對應的生成圖片。示範資料只會由 seed（#59）寫入本機與 preview，不寫入 production。

## 圖片來源

- 2026-10-01 以 Codex CLI 0.159.3 的 `image_generation` 生成，非互動執行 `codex exec`，每張圖一次呼叫。
- 每張圖的 prompt 記在 `catalog.json` 對應的 `prompt` 欄位，共同風格段落在 `style`。
- 原始 PNG 以 `sips` 轉為 JPEG（品質 80），不縮放、不裁切。
- 共 55 張：商品照 47 張、分類情境照 4 張、首頁主視覺 3 張、編輯式橫幅 1 張。

## 已知限制

- 同一件商品的多角度圖是分別生成的，造型細節可能略有差異。示範用途可以接受。
- 首頁主視覺的主體位置不一定都偏右，套用到首頁版面（#58）時要依實際構圖調整文字位置。
