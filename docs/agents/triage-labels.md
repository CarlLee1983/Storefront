# Triage Labels

| Canonical role | GitHub label | 用途 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交給 agent |
| `ready-for-human` | `ready-for-human` | 需要人員處理 |
| `wontfix` | `wontfix` | 不會處理 |

執行 triage 時，以右欄標籤名稱操作 GitHub。
