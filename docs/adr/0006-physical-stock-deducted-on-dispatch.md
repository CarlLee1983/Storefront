# 付款保留商品，交付物流才扣實體在庫

家居商品可分批出貨，付款成功時商品仍在倉內；沿用付款時扣在庫的方式，會讓倉庫盤點與已付款待出貨數量難以核對。依設計訪談 Q7，目標模型分開記錄實際在庫、待付款保留與已付款待出貨保留：付款只轉換保留性質，每批真正交付物流時才扣除對應實體數量。

這取代目前付款時扣 `onHand` 的行為，屬目標決策，尚未實作；不能只修改出貨流程而保留付款扣庫，否則會重複扣除。Q13 進一步確認實體在庫包含待檢／損壞退貨，這些數量另列不可售，實際收回才增加實體在庫，檢查合格只將不可售轉可售；報廢移出倉庫才減少實體在庫。

Q22 已確認保留式遷移：舊已付未出貨數量加回實體在庫，同時建立已付款保留，不能增加可售；舊已出貨不加回。實作前仍須核對資料與例外，不能以狀態代替盤點或臆造物流證據；ADR 0001 的遲到付款重新保留或退款原則不因本決策取消。
