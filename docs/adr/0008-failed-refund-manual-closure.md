# 明確失敗的退款是否可人工結案並釋放額度

ADR 0007 規定明確失敗的退款保留額度並列待處理。#115 實作後，失敗那筆沒有任何結案路徑：例如顧客卡片已停用、閘道每次都明確拒絕時，這筆會永久佔用額度、永久留在退款待辦與訂單「需要處理」，管理員只能反覆重試；改走線下退款或決定不退時，系統也無處記錄。#116 起同一筆付款會有多筆部分退款，這個缺口會更常出現。

候選做法（#115 複審提出，尚未決定）：新增終態「人工結案」，只允許從明確失敗轉入（結果不明必須先查證確認款項未退），記錄操作者、原因與處理方式（線下已退／決定不退），並釋放其佔用額度。待決問題：釋放的額度能否再承諾給其他退款案件、是否需要顧客通知、發票折讓（#121／#122）如何對待人工結案。

**Falsified if:** 閘道明確失敗的退款在 `apps/app/src/payments/refunds.ts` 已有不需重試即可結案或釋放額度的路徑，或使用者決定明確失敗只能靠重試解決。
