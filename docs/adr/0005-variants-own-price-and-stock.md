# 以商品變體作為可販售與庫存計算單位

家居商品的尺寸、顏色可以有不同價格與庫存，因此商品保留共同介紹，實際選購、定價與庫存計算以商品變體為單位；沒有選項的商品仍可販售。相較於把每個顏色與尺寸都建立成獨立商品，這個選擇保留同款商品的共同展示，同時讓不同選項不共用錯誤庫存。

本決策於設計訪談 Q3 確認，描述目標模型，尚未實作。它會改變購物車、訂單明細與庫存識別的邊界；Q22 已確認既有商品轉預設變體、舊單保留實付單價與既有交易金額；精確映射及例外須在實作前驗證，不能直接把既有資料視為已符合新模型。

實作狀態：T01（#104）已實作預設變體（每個商品一個、購物車／結帳／訂單明細／庫存以變體為單位）；多變體、選項維度與停賣留給後續票。
